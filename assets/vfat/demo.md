# CDC Badge

Welcome to your badge's **file viewer**.

## Markdown support

- Bulleted lists
- *Emphasis* and `inline code`
- [Links](https://example.com): select with 4 / 6 and open with Y

Select the image link with 4 / 6 and press Y to open it:

![demo image](demo.jpg)

### Code blocks

```
hello, world
```

> Block quotes are set off like this.

## Task list

Select a checkbox with 4 / 6 and toggle it with Y. Changes are saved back to
this file.

- [ ] Read the welcome text
- [x] Flash the firmware
- [ ] Try the image viewer

---

Open **demo.jpg** from this folder to try the image viewer
(baseline and progressive JPEG, plus PNG, dithered to black and white).

Open **demo.html** to try the text browser's reader on a local file, including
its in-page links and a sample form.
