Browser demo

This local file shows how the badge text browser renders HTML: navigation, scripts and styling are stripped and the readable article body is kept and wrapped to the screen width.

Headings

Headings map to Markdown sizes, so this section title is shown larger than the body text, exactly like a remote page would be rendered.

Links

In-page links are numbered. Select one with 4 / 6 and open it with Y: visit Example or the about page to follow a link over Wi-Fi.

Form

Forms are interactive too. Select the checkbox and the submit control with 4 / 6; Y toggles the checkbox and activates submit.
